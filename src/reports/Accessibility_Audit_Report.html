Impact: Screen reader users cannot identify form field purpose
Fix Applied: Added proper <label> elements with for attributes and converted fieldset+legend structures
Keyboard Trap in Date Widget (inscription.html)
Impact: Keyboard-only users cannot escape the widget
Fix Applied: Removed custom widget, replaced with native <input type="date">

Impact: Users with disabilities cannot interact within time constraints
