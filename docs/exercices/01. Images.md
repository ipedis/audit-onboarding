# Images

## Pages à tester

`index.html` et l’en-tête partagé présent sur les pages du site.

## Objectif

Qualifier chaque image (décorative, informative, fonctionnelle, image-texte ou complexe), puis vérifier l’existence et la pertinence de son alternative.

## Protocole

1. Inventorier les éléments `img`, les éléments ayant `role="img"`, les SVG et les images CSS.
2. Pour chaque image, noter son rôle dans le contexte et déterminer si sa suppression ferait perdre une information ou une action.
3. Pour une image porteuse d’information, vérifier la présence d’une alternative textuelle (critère 1.1), puis sa pertinence (critère 1.3).
4. Pour une image fonctionnelle, comparer le nom accessible avec la fonction ou la destination.
5. Pour une image complexe, vérifier si une description détaillée restitue toutes les données utiles (critère 1.6).
6. Contrôler au clavier et avec le lecteur d’écran les images incluses dans un lien ou un bouton.

## Preuves attendues

Pour chaque cas : page, emplacement, rôle retenu, extrait DOM ou nom accessible, critère et conclusion conforme/non conforme. Un critère n’est conforme que si tous ses éléments applicables passent les tests.
