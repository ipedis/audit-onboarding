# Éléments obligatoires

## Pages à tester

`about.html`, `faq.html`, `index.html`, `index.fr.html`, `pricing.html` et `contact.html`.

## Protocole

1. Vérifier la présence et la validité du type de document (8.1).
2. Valider le code et relever les erreurs qui affectent l’accessibilité (8.2).
3. Vérifier la langue par défaut (8.3) et la pertinence de son code (8.4).
4. Vérifier la présence d’un titre de page (8.5) et sa pertinence (8.6).
5. Repérer les passages dans une autre langue et vérifier leur indication programmatique (8.7).
6. Contrôler la validité des changements de sens de lecture, s’ils existent (8.8).
7. Examiner les balises utilisées uniquement pour obtenir une présentation visuelle (8.9).

## Méthode

Comparer le DOM, le code source, l’onglet du navigateur et le résultat d’un validateur HTML. Pour les langues, écouter les passages avec un lecteur d’écran configuré avec les voix nécessaires. Pour la présentation, désactiver les styles et distinguer structure et effet visuel.

## Preuves attendues

Pour chaque page et critère : élément contrôlé, extrait minimal du code, résultat observable, impact et conclusion conforme/non conforme/non applicable. Une erreur de validation sans incidence sur l’accessibilité ne suffit pas seule à invalider 8.2.
